# 💝 时光纪念册

时光纪念册是一款温馨的桌面应用，专为记录恋爱中的珍贵瞬间而生。无论是相识的纪念日、每天的心情日记、甜蜜的合照视频，还是两人之间数不清的聊天记录，都可以在这里被温柔地收藏起来。

应用拥有启动密码保护，所有数据都保存在你的电脑本地，不会上传到任何云端服务器，给你的回忆最安全的守护。

---

## 📅 纪念日

纪念日是时光纪念册的核心功能，帮你精确记录两人相识的每一个"此时此刻"。

### 实时计时

首页会在最醒目的位置展示你们从认识那天起到现在的总时长，精确到**天、时、分、秒**，数字每秒跳动，让你真切地感受到时间的厚度。天数的数字会以特大字体呈现，下方还会显示时、分、秒的精确数值。

### 感情历程追踪

支持记录相识至今的多段分手与复合经历。每段分手/复合记录都可以精确到具体的时间点，系统会自动分段计算：

- **在一起的总时长** —— 所有在一起的日子的总和
- **分开的总时长** —— 所有分开的日子的总和
- **当前感情状态** —— 在一起中 / 已分开

如果当前处于"已分开"状态，首页会同时显示在一起的总天数和分开的总天数。

### 里程碑自动标记

系统内置了 21 个里程碑节点，从认识到一周年、百天纪念、520 天到五周年等等。已达成的高亮显示并标注达成日期，下一个即将到来的里程碑会闪烁提示，让你不错过每一个值得庆祝的日子。

### 生日倒计时

在设置中填写她的生日后，首页会自动显示距离她下一个生日的剩余天数。

## 📖 心情日记

日记功能支持 Markdown 语法，让你可以用丰富的格式记录每一天的心情。

### 日历视图

左侧边栏展示月历，有日记的日期会以主题色高亮标注，并显示当天日记的字数。点击任意日期即可切换到当天的日记。你可以自由地在不同的月份之间切换浏览。

### Markdown 编辑器

日记编辑器内嵌了功能完整的 Markdown 工具栏，支持：

- **标题**（H1 ~ H4）
- **文字样式**：加粗、斜体、下划线、删除线
- **代码**：行内代码、代码块（带语法高亮深色背景）
- **引用块**（带粉色左边框）
- **列表**：无序列表、有序列表、任务列表
- **链接和图片**：点击插入链接，或直接上传图片到日记中
- **分割线**和**表格**

编辑器支持三种视图模式：

- **编辑模式**：纯文本编辑，所见即代码
- **分屏模式**：左侧编辑 Markdown 源码，右侧实时预览渲染效果
- **预览模式**：全屏预览，隐藏编辑区和工具栏，如阅读一篇排版精美的文章

此外还支持 `Ctrl+B` 加粗、`Ctrl+I` 斜体、`Ctrl+U` 下划线等快捷键。

### 心情标签

每篇日记都可以选择一种心情，共 20 种心情可选，涵盖开心、甜蜜、心动、想念、感动、平静、难过、焦虑等，每种心情都有对应的 emoji 表情。

### 实时字数统计

编辑器顶部实时显示当前日记的字数。字数统计会去除空格，只计算实际文字。保存后后端会重新校验字数，确保数据准确。

### 搜索与统计

- **搜索**：在左侧边栏的搜索框中输入关键词，可以快速筛选出包含该内容的日记。
- **统计面板**：显示总篇数、总字数、本月日记数、平均每篇字数。
- **日记列表**：按时间倒序展示所有日记，鼠标悬停可看到编辑和删除按钮。

## 📸 情侣相册

相册功能用来收藏两人的照片和视频，支持分类管理和多种浏览方式。

### 相册分类

系统默认提供「日常」「旅行」「纪念日」三个分类，你也可以创建自定义分类。照片上传到哪个分类就显示在哪个相册中。顶部标签栏会显示每个分类的照片数量。

### 瀑布流展示

照片采用瀑布流（Masonry）布局，自动适应照片的原始比例排列，视觉效果丰富而有层次感。照片悬停时会微微上浮并显示阴影，底部浮现上传日期和备注信息。

### 上传支持

- **照片**：支持 jpg、jpeg、png、gif、bmp、webp 格式，可多选批量上传
- **视频**：支持 mp4、avi、mov、mkv、webm 格式，可多选批量上传

### 点击查看与幻灯片

点击任意照片或视频会打开全屏查看器。在查看器中可以使用键盘**左右方向键**切换上一张/下一张，按 `Esc` 键关闭。

点击导航栏右侧的幻灯片按钮，会从当前相册的第一张开始，每 3 秒自动切换，循环播放，适合在大屏幕上展示两人的回忆。

## 💬 聊天记录

聊天记录功能可以将你和她在各平台的聊天记录导入到时光纪念册中，统一浏览、永久保存。

### 多平台支持

支持从以下平台导入聊天记录（共 12 个平台）：微信、QQ、钉钉、Telegram、WhatsApp、Line、Signal、飞书、Skype、Messenger、短信、其他。

### 多格式兼容

支持导入以下文件格式的聊天记录：

- **HTML / HTM**：微信、QQ 导出的聊天记录网页文件
- **CSV**：表格格式的聊天数据
- **JSON**：结构化聊天数据
- **TXT**：纯文本聊天记录
- **Word (.docx)**：Word 文档格式
- **Excel (.xlsx / .xls)**：Excel 表格格式

系统会自动识别不同格式中的时间、发送者、消息内容，无需手动处理。

### 聊天浏览

导入后：

- 左侧展示聊天记录列表，按平台分组
- 点击任意聊天记录，右侧以**聊天气泡**形式展示消息内容
- 消息按日期分隔，时间与发送者清晰标注
- 支持按平台筛选查看

### 统计面板

顶部统计栏会显示：导入记录总数、消息总数、涵盖平台数量。

## 🔒 隐私保护

时光纪念册将隐私安全放在首位。

### 启动密码

首次启动时需要设置一个启动密码，之后每次打开应用都需要输入密码才能进入。密码采用 SHA-256 加密存储，任何人无法在不知道密码的情况下查看你的数据。

### 本地存储

所有数据都保存在你电脑的本地目录（`%APPDATA%/time-memorial/`），包括：

- `settings.json` —— 设置信息（密码已加密）
- `diaries.json` —— 日记数据
- `albums.json` —— 相册分类
- `photos.json` —— 照片和视频的元信息
- `photos/` —— 照片文件
- `videos/` —— 视频文件
- `chats.json` —— 聊天记录

没有任何数据会被上传到云端或第三方服务器。

### 数据备份与恢复

在「设置 → 数据管理」中，可以：

- **导出备份**：将所有数据（日记、照片元信息、相册、聊天记录等）打包为一个 JSON 文件
- **导入备份**：从之前导出的备份文件恢复数据

### 一键初始化

在设置页面提供「初始化所有数据」功能，需要输入密码确认后，会清空所有日记、照片、视频、聊天记录，将应用恢复到初始状态。

## 🎨 个性化外观

### 双主题切换

提供两套精心设计的主题配色：

- **甜蜜粉**：以粉色系为主，温暖柔和，适合热恋中的心境。
- **思念蓝**：以蓝色系为主，沉静内敛，适合思念或平静的时光。

切换主题后，所有页面的主色调、背景色、卡片的阴影和渐变效果都会统一改变，瞬间切换整体氛围。当前主题设置会自动保存，下次打开应用时保持不变。

## ⚙️ 设置

### 纪念日设置

- **认识日期与时间**：精确到分钟，点击"此刻"按钮可以直接设为当前时间
- **她的生日**：用于首页的生日倒计时显示

### 分手 / 复合记录

- 支持添加多组分/复合记录
- 每组记录包含精确的「分手时间」和「复合时间」
- 需完成上一组记录（填写了分手和复合时间）后才能添加下一组
- 只允许删除最后一条记录，保证时间线的连续性

### 安全设置

- 修改启动密码（需验证当前密码）

## 💡 使用建议

1. **首次使用**：打开应用 → 设置启动密码 → 进入后点击「设置」→ 填写认识日期和她的生日 → 保存。
2. **每天写日记**：点击导航栏「日记」→ 在日历上选中今天 → 选择心情 → 用 Markdown 写下你想说的话 → 点击保存。
3. **上传照片**：点击导航栏「相册」→ 先选择合适的分类 → 点击上传照片或上传视频按钮。
4. **导入聊天记录**：点击导航栏「聊天记录」→ 点击导入按钮 → 选择平台和文件 → 开始导入。
5. **更换主题**：点击「设置」→ 在外观设置中选择甜蜜粉或思念蓝 → 保存设置。
6. **定期备份**：点击「设置」→ 数据管理 → 导出备份，将备份文件保存在安全的位置。
